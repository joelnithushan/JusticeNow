# Security Policy

## Responsible Disclosure
We take security seriously. If you discover a vulnerability in JusticeNow, please **report it privately** to us using the following contact:

- **Email:** `security@<your-domain>`

Replace `<your-domain>` with the appropriate domain for the organization before publishing.

## Expected Response Time
We aim to acknowledge receipt of a vulnerability report within **48 hours** and provide a substantive response or remediation timeline within **5 business days**.

## Supported Versions
This policy applies to all versions of JusticeNow that are currently released and maintained in the `main` branch of the repository.

## Reporter Anonymity
JusticeNow is designed to protect the anonymity of reporters:
- **No reporter identity is ever stored** in the system. The only identifier for a case is a `reference_code` generated at submission.
- All logs, databases, and audit trails are free of personal identifiers for reporters.
- Evidence files are served via short‑lived signed URLs; no permanent public URLs are used.
